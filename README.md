# 🚀 Projet de fin de formation – Développement Web & Web Mobile

Ce projet a été présenté lors de mon passage devant le jury dans le cadre de ma formation en développement web et web mobile.
Il illustre ma capacité à concevoir une application full stack moderne, en utilisant React pour le front-end et Node.js/Express pour le back-end.

## 🎯 Objectifs du projet

- Créer une application web fonctionnelle avec une architecture client/serveur
- Gérer les routes, les appels API et la persistance des données
- Mettre en œuvre une interface utilisateur dynamique et responsive
- Respecter les bonnes pratiques de développement et de sécurité

## 🛠️ Stack technique

- **Front-end** : React, JSX, CSS Modules 
- **Back-end** : Node.js, Express
- **Base de données** :  MySQL
- **Outils** : GitHub, Postman, Visual Studio Code , Figma, trello
